# Draftly 设计系统（编辑工作室版）

> 已确认方向：**功能页以白色为主，绿色只用于可交互元素与品牌识别；首页使用暖白纸感与超大衬线字标；后台登录用一块深绿“back room”形成对照。**
> 2026-10-29 在原有绿色版基础上增加品牌首页、反馈表单、隐私/条款页与管理员后台，不改变编辑器内部结构。

## 1. 设计原则

1. **白底优先**：编辑器、设置、功能页使用纯白；浅色只用于分区和输入控件。
2. **绿色即交互**：主按钮、选中状态、当前导航、链接、焦点环使用品牌绿；装饰不抢交互。
3. **暖色做层次**：暖米白承担次级表面，琥珀只用于“替代表达 / 提示 / 过渡点”，不用于主操作。
4. **编辑感**：首页、Legal 页与后台大标题使用衬线字体与紧字距；正文、表单与控件保持无衬线，保证中英文可读性。
5. **轻量质感**：1px 暖灰边框 + 极浅阴影，不使用紫色渐变、发光或厚重投影。
6. **文字优先**：中文正文 15–16px，行高 1.75–1.85；标题使用深墨绿黑，避免纯黑生硬。

### 语义高亮

- **改写新增**：`--success-bg #E5F5EA` 底 + `#14532D` 字，不使用品牌绿实底，避免与按钮混淆。
- **替代表达**：`--accent` 琥珀色波浪下划线，保持与绿色改写高亮的区分。
- **禁止**：`#4F46E5`、`#7C3AED`、`#6366F1` 等旧蓝紫色；首页大面积渐变背景。

### 对比度（白底）

| 组合 | 对比度 |
| --- | --- |
| 正文 `#1B241F` / 白 | 15.9:1 |
| 次要文字 `#637069` / 白 | 5.2:1 |
| 主色 `#0B6B53` / 白 | 6.5:1 |
| 白字 / 主色按钮 | 6.5:1 |
| 琥珀 `#B45309` / 白 | 5.0:1 |

均达到 WCAG AA 正文标准。

## 3. 字体

界面无衬线：

```css
font-family: "Segoe UI Variable", "Segoe UI", -apple-system,
  BlinkMacSystemFont, "PingFang SC", "HarmonyOS Sans SC",
  "Microsoft YaHei UI", "Microsoft YaHei", "Noto Sans SC",
  ui-sans-serif, system-ui, sans-serif;
```

展示衬线（仅首页字标、大标题、Legal 标题与后台标题）：

```css
font-family: "Iowan Old Style", "Palatino Linotype", "Book Antiqua",
  Georgia, "Songti SC", "STSong", "SimSun", serif;
```

- 不引入外链 Google Fonts，避免国内网络与构建时字体请求失败。
- 拉丁字符优先 Segoe UI，中文回退苹方 / 鸿蒙 / 微软雅黑。
- 编辑器标题 `font-semibold`、`tracking-tight`；正文保持 1.75 行高。
- 首页字标 `clamp(4rem, 8.5vw, 7.5rem)`（桌面左栏），字距 -0.075em；移动端 `clamp(3.6rem, 16vw, 5.4rem)`，保证单行不裁切。

## 4. 形状与阴影

| Token | 值 | 用途 |
| --- | --- | --- |
| `--radius-lg` | 18px | 卡片、首页 hero |
| `--radius-md` | 12px | 输入框、按钮 |
| `--radius-sm` | 9px | 小控件 |
| `--shadow-sm` | `0 1px 2px rgba(23,33,28,.04)` | 小浮层 |
| `--shadow` | `0 20px 44px -34px rgba(23,33,28,.28)` | 卡片 |

卡片使用**边框 + 极浅阴影**，不依赖重投影。选中导航使用 `inset 3px 0 0` 的左侧绿线，不改变布局。

## 5. 组件规则

- **主按钮**：实底 `--primary`、白字、绿色轻投影；hover 变为 `--primary-strong`，仅上移 1px。
- **次按钮**：白底 + 边框；hover 出现浅绿底与绿色文字。
- **标准胶囊**：未选中白底灰边；选中实底绿 + 白字。
- **分段控件**：暖米白底；选中为白底 + 深绿字，不整块变绿。
- **导航**：当前项浅绿底 + 深绿字 + 左侧 3px 绿线。
- **输入框**：白底、暖灰边框；focus 用绿色边框 + 12% 透明绿光环。
- **提示条**：info 用暖米白，success 用浅绿，warning 用琥珀，error 用红；不使用紫色 info。
- **差异高亮**：新增用浅绿底，删除用浅红删除线，替代用琥珀波浪线。
- **首页 Hero**：桌面 45% 左文案 / 5% 柔和过渡线 / 50% 固定产品演示；暖白纸张底 + 极淡径向绿光；字标衬线、左对齐；主 CTA 为绿色胶囊，白色箭头圆点，hover 上移 2px 且箭头右移 3px。移动端按“品牌与文案 → CTA → 演示”纵向排列。
- **产品演示卡**：固定示例，标注“仅用于展示”；`BEFORE` / `AFTER` 两个面板，AFTER 逐词出现、绿色下划线标记改写词，结束停留后循环；提供暂停/重播，`prefers-reduced-motion` 下直接展示最终结果。不调用 API、不遮挡 CTA。
- **工具卡**：白/半透明白底 + 1px 边框，编号用衬线斜体；五张工具卡 + 一张虚线说明卡；hover 上移 3px、边框转浅绿、图标底变浅绿；仅第一张使用轻微绿色渐变。
- **润色词替换**：仅 AI 改写词可交互，浅绿底 + 点状下划线；桌面悬停 240ms、移动端点击打开固定定位浮层；浮层白底、18px 圆角、3–5 个候选，候选最小高度 44px；Escape/外部点击关闭并把焦点还给原词；替换成功用底部胶囊提示“可用撤销恢复”。
- **反馈表单**：白色面板、18–22px 圆角；标签小号大写 + 中文辅助；输入框 `#FCFCF8` 底，focus 绿边 + 4px 10% 绿光环；成功态用绿色勾圆与双语感谢；错误在表单顶部与字段旁同时出现。
- **后台**：桌面表格 + 移动卡片；状态胶囊用琥珀（新）/浅绿（处理中、已解决）/灰（已归档）；详情用底部弹出的抽屉式面板，移动端全宽。
- **管理员登录**：桌面左侧深绿品牌面板（仅此一处大面积深绿），右侧暖白表单；移动端隐藏品牌面板，在表单上方显示小字标。

## 6. 动效

- 交互过渡 150–220ms；按钮 hover 上移不超过 2px，工具卡不超过 3px。
- 加载条使用绿色渐变滑轨；保留 `prefers-reduced-motion` 降级，关闭位移、打字动画、脉冲与平滑滚动。
- 首页演示的逐词动画只用于说明产品行为；不使用持续发光、漂浮或大面积渐变动画，不使用自动轮播或视频。

## 7. 禁止项

- 紫色 / 靛蓝 / 蓝紫渐变（尤其是 `#7C3AED`、`#4F46E5`）。
- 功能页大面积绿色页面底色；首页绿色只作为柔和径向光，不铺满。
- 绿色实底用于“改写新增”文本（会与主按钮混淆）。
- 多个同等强度的绿色按钮并排竞争；Hero 只保留一个主 CTA。
- 外部字体阻塞首屏；用 emoji 代替 SVG 图标。
- Footer 固定悬浮、遮挡内容；使用多列企业官网式友情链接墙。
